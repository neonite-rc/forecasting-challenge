# Screenshots

Place documentation screenshots here using the naming convention from
[`../SCREENSHOT_GUIDE.md`](../SCREENSHOT_GUIDE.md), e.g.

```text
01_pytest.png
02_predict_cli.png
03_predictions_csv.png
...
16_fig09_calibration.png
```

PNGs of terminal runs and report figures are small and safe to commit. The
challenge dataset itself must never be added here or anywhere in the repo.
